# Pixel Quest

Компактный 2D pixel-art платформер на HTML5 Canvas (без сборщиков и зависимостей).

**[🔗 Live Demo](https://pixel-art-game-nine.vercel.app)**

## Запуск

Откройте `index.html` в браузере (двойным кликом). Сервер не нужен.

## Управление

- A / D / стрелки — движение
- W / стрелка вверх / Space — прыжок (держите дольше — выше)
- Прыжок сверху на слайма — убить его
- P / Esc — пауза (Resume / Restart / Main menu)
- M — выключить звук
- В меню: стрелки вверх/вниз + Enter

## Правила

3 уровня (Green Hills, Sunset Ridge, Midnight Pass). Цель — дойти до флага.
3 сердца; шипы, враги и пропасти отнимают сердце. За каждый пройденный уровень +1 сердце (максимум 3).
Очки: монета +10, враг +50, уровень +100. Рекорд хранится в localStorage.

## Технические детали

- Фиксированный шаг 60 Гц, целочисленное масштабирование, `image-rendering: pixelated`.
- Логическое разрешение 320x192.
- Файлы: `js/levels.js` (уровни), `entities.js` (физика, игрок, враги), `input.js`, `audio.js`, `sprites.js`, `main.js`.

## Ассеты и лицензии

Внешние ассеты не используются. Все спрайты нарисованы программно (`js/sprites.js`),
звуки и музыка синтезируются Web Audio API (`js/audio.js`). Весь код и графика
оригинальные, распространяются как CC0 / public domain.
Папка `assets/` оставлена для ваших собственных спрайтов и звуков.
